Ako používať almanach
How to use this almanac
Toto je kurátorovaný referenčný výber 393 unikátnych transakčných kódov, nie oficiálny úplný register
všetkých SAP transakcií. Účelom je rozumieť, kde začať, ako spolu systémy súvisia a aké riziko má daná akcia.
This is a curated selection of 393 unique transaction codes, not an official exhaustive register. Its purpose is orientation, process
awareness and safe triage.
ZÁSADNÉ / ESSENTIAL
Prítomnosť T-kódu sa líši podľa produktu, release, aktívnych komponentov, zákazníckej konfigurácie a oprávnení.
Kód „existuje“ neznamená, že je vhodný pre cieľový postup.
Availability varies by product, release, component activation, customizing and authorizations. Existence does not
equal recommended usage.
Legenda značiek / Legend
R — Zobrazenie / čítanie Read / inspect
W — Vytvorenie / zmena / účtovanie Write / change / post
A — Administrácia, nastavenia, silný dopad Administration / elevated impact
O — Voliteľný modul alebo závislosť od verzie Optional component / release-specific
L — Legacy, nahradené alebo problematické v S/4 Legacy / replaced / S/4 caveat
Značka vyjadruje primárny charakter, nie záruku oprávnenia ani bezpečnosti. Aj „R“ môže sprístupniť citlivé
údaje; „W“ ani „A“ nikdy nespúšťaj na produkcii bez oprávnenia, testu a schválenia.
Tags describe typical intent, not permissions or safety. Read-only screens may reveal sensitive data; writes and administrative
changes require proper controls.

SAP BTP ABAP Environment Bez SAP GUI; vývoj cez Eclipse ADT, ABAP Cloud, released APIs, CDS a RAP.
Táto príručka je tu najmä procesný kontext.
No SAP GUI; develop in Eclipse ADT using ABAP Cloud [S03, S04].
5 pravidiel pri práci / Five operating rules
01. Zisti systém, klienta, release a prostredie skôr než čokoľvek spustíš.
Identify product, client, release and landscape first.
02. Začni diagnostikou a presným dokladom, nie náhodným preklikávaním.
Start with a document ID and observable evidence.
03. Odliš problém dát, procesu, konfigurácie, kódu a oprávnenia.
Separate data, process, customizing, code and authorization issues.
04. Pri dávkových opravách ošetri duplicity, rollback a idempotenciu.
For bulk recovery, consider duplicates, reversibility and idempotency.
05. Po oprave urob technické aj biznis overenie s vlastníkom procesu.
Perform technical and business validation with the process owner.
Ako si overiť konkrétny T-kód / Verify in your system
1. V SE93 vyhľadaj definíciu a balík. 2. V SE16N/SE16H vieš autorizovane prezrieť TSTC/TSTCT. 3. Skontroluj, či
má používateľ S_TCODE, súvisiace procesné oprávnenia a Fiori role. 4. Potvrď vhodnosť pre konkrétny release v
SAP Help, Simplification List a Fiori Apps Reference Library [S01, S02, S16].
Use SE93/TSTC/TSTCT to verify existence, security tools to verify authorization, and release documentation to confirm whether it
remains a recommended flow.

Odporúčaná stopa / Suggested trace
